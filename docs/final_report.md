# Final Report

## 프로젝트 요약

`agent_base`는 Python HTTP API와 React GUI를 연결한 간단 챗봇 베이스입니다.

## 사용 기술

- Python 표준 라이브러리 HTTP 서버
- React
- Vite
- lucide-react
- OpenAI-compatible Chat Completions
- Gemini generateContent
- Anthropic Messages API
- Ollama local API

## 구현 기능

- Mock 기반 챗봇 응답
- OS 선택 및 엔진 선택 GUI
- Provider 설정 패널
- Windows/macOS 실행 스크립트
- 안전한 파일 읽기 Tool
- 메모 저장 Tool
- 지식 문서 검색 Retriever
