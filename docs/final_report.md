# Final Report

## 프로젝트 요약

`agent_base`는 Python Agent 템플릿을 React GUI까지 확장한 학습용 프로젝트입니다.

## 사용 기술

- Python 표준 라이브러리 HTTP 서버
- React
- Vite
- lucide-react

## 구현 기능

- Mock 기반 Python 문법 오류 분석
- OS 선택 및 엔진 선택 GUI
- Windows/macOS 실행 스크립트
- 안전한 파일 읽기 Tool
- 메모 저장 Tool
- 지식 문서 검색 Retriever

## 선택 확장

- OpenAI API 연결
- Ollama 로컬 LLM 연결
- Render 배포
